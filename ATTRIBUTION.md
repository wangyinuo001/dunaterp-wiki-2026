# Website attribution register

- Team-authored website content: SCU-China 2026, intended for release under CC BY 4.0 after team review.
- Interaction and architecture reference: Bruno Simon, [Folio 2025](https://github.com/brunosimon/folio-2025), MIT License. The DunaTerp homepage adapts the repository's scroll/input smoothing, cinematic camera transition, active-section state and split preview/content navigation (notably `Menu.js`, `ProjectsArea.js` and `LabArea.js`). The miniature-algae collision field ports the force structure from `Leaves.js`—vehicle-velocity push plus radial push, multiplied by speed and distance falloff—then retunes it for a small CPU simulation and adds original camera/particle feedback. `Bricks.js` was studied for its dynamic-body parameters, but this prototype does not claim to reproduce its Rapier rigid-body vehicle. All React/Three.js scene code and project-specific procedural geometry were independently written. No Folio artwork, 3D models, audio, fonts or texture files are redistributed.
- Scientific figures currently shown: generated by analysis scripts in this project workspace. Dataset sources, methods and figure-level licences must be verified and added inline before publication.
- Procedural *Dunaliella salina* model: an original, diagrammatic model based on published morphology—oval/pear-shaped wall-less cell, two equal anterior flagella, cup-shaped chloroplast, central pyrenoid and anterior eyespot. No microscopy image was copied. Morphology reference: Friedl et al., *Algal Research* 2020, https://doi.org/10.1016/j.algal.2020.102066.
- Miniature collision algae and impact rings: original procedural decorative objects used to communicate motion and interaction. Their bouncing behaviour is not a simulation of algal biology or experimental evidence.
- Saltworks buildings, photobioreactors, light array, wet-lab bench, carotenoid pathway hub, product tanks and sustainability station: original procedural scene props. They are conceptual illustrations, not records of built hardware or experimental evidence.
- OpenAI Codex (GPT-5 family): website scaffolding, interface code, navigation, accessibility structure and clearly marked copy drafts on 2026-08-15.

## Pixel homepage — 2026-09-08

- **Anthropic Claude (Opus 5): pixel-art homepage.** Replaced the Three.js/Rapier scroll journey with an original 2D pixel-art salt lake rendered on a 2D canvas (`src/pixel/`, `src/PixelWorld.tsx`, `src/pixel.css`). Interaction concept — a navigable world in which moving through space is how the site is browsed — remains credited to Bruno Simon, [Folio 2025](https://github.com/brunosimon/folio-2025), MIT License; no Folio code, artwork, models, audio, fonts or textures are used or redistributed in this version. The overall visual register (16px tiles, orthographic top-down view, limited palette, hand-placed props) is a widely used pixel-art convention, referenced generally to the look of *Stardew Valley*; no ConcernedApe assets, tilesets, sprites, palettes or code were examined, copied or redistributed.
- **Original September implementation:** all pixel art was generated by team-owned code, not by importing image files. Every tile, prop, station and character frame is drawn at runtime from a fixed palette (`src/pixel/palette.ts`) through a small drawing helper (`src/pixel/paint.ts`). The hero sprites are hand-authored character grids in `src/pixel/sprites.ts`; everything else is painted procedurally. The 5×7 bitmap typeface in `src/pixel/font.ts` was authored glyph by glyph for this project. No sprite sheet, tileset, font file or asset pack from any third party is bundled or referenced.
- **Salt-pan terrain.** The polygonal crust is a jittered Voronoi plate field, an original implementation of a standard procedural technique. The pink and amber ponds depict carotenoid pigmentation of hypersaline evaporation ponds by *Dunaliella salina*; they are diagrammatic, not derived from any photograph or dataset.
- **Station structures** (sampling tower, cell exhibit, light array, model hut, product tanks, commons pavilion, archive gatehouse): original procedural scene props. They are conceptual illustrations, not records of built hardware or of experimental evidence.
- **Pixel *Dunaliella salina* model**: the same original diagrammatic morphology previously used in the 3D scene — wall-less oval cell, two equal anterior flagella, cup-shaped chloroplast, central pyrenoid, anterior eyespot — redrawn in pixel form. Morphology reference unchanged: Friedl et al., *Algal Research* 2020, https://doi.org/10.1016/j.algal.2020.102066.
- **Offline art check** (`tools/art-check/`): an original minimal Canvas2D rasteriser and PNG encoder written for this project so the art can be reviewed as images without a browser. It is a development tool and ships nothing to the site.
- No scientific page content, figure, dataset or claim was changed in this work. Human review is pending; no scientific review and no browser or device verification is claimed.
